# Quick Start Guide

## Installation & Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   The app will automatically open at `http://localhost:3000`

## Project Structure

- `src/components/` - All React components
- `src/contexts/` - React Context providers
- `public/images/` - Static image assets
- `css/` - CSS files (Bootstrap, custom styles)
- `index.html` - Main HTML file (Vite entry point)

- React 18
- Vite 4
- Bootstrap 5
- Swiper 9
- React Hooks & Context API

## Notes

- Images are served from `public/images/`
- CSS files are imported in `src/index.css`
- Original HTML file saved as `index-original.html`
- All SVG symbols are in the `SVGSymbols` component
